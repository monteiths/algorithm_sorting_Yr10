Investigate

Try this: Start with 10 unsorted items using Bubble Sort. Repeat with 100 and 500. What changes? Then try an already sorted list. Repeat the experiment with Selection Sort and Quick Sort. Which algorithm makes fewer comparisons or scans as n increases?

Teacher note: Bubble Sort here uses the classroom fixed-pass model (it does not stop early when no swaps occur). Selection Sort scans the unsorted remainder and swaps only when needed. Quick Sort uses the LESS / EQUAL / GREATER grouping model with the first item as pivot; a classification counts as a scan and moving items into groups counts as moves. This visualisation shows a sorting process, not a benchmark of execution speed.
